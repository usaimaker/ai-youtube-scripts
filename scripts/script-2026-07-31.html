Why this matters

Cloud AI tools charge monthly, and every prompt leaves your machine. Local models flip that. After one free download, you get unlimited queries, offline access, and data that never travels. For anyone handling client files or contracts, that privacy is the real win.

1. LM Studio for total beginners

LM Studio is a free desktop app. No terminal, no code. Download it from lmstudio.ai, open the Discover tab, and search a model. Pick the Q4_K_M version. That quantisation shrinks the model about four times with little quality loss. Then chat, exactly like ChatGPT.

2. Ollama for anyone who likes a terminal

Ollama installs in one command. Type "ollama pull llama3.2" and then "ollama run llama3.2". Done. It also starts a local server on port 11434. That server speaks the OpenAI API format, so your existing scripts work unchanged.

3. Match the model to your RAM

Hardware decides everything here. With 8GB RAM, stick to 1B to 3B models for simple tasks. With 16GB, run 7B or 8B models comfortably. With 32GB or more, 14B to 30B models get close to cloud quality. Apple Silicon Macs punch above their weight, because CPU and GPU share memory.

4. Pick the right model for the job

Llama 3.2 3B is tiny and fast. Mistral 7B handles coding and analysis well. Gemma 2 9B gives clean, structured reasoning. Qwen 2.5 Coder 7B is strong for debugging. Phi-3 Mini runs on weak hardware. Start small, then upgrade.

5. AnythingLLM turns documents into answers

AnythingLLM connects to Ollama or LM Studio. Drop in PDFs, notes, or whole folders. It builds embeddings locally and lets you ask questions. Nothing gets uploaded. It is a private knowledge base for contracts, SOPs, or research.

Automation tip

Point any OpenAI-compatible tool at http://localhost:11434/v1 and use "ollama" as the key. Your automations then run on free local inference instead of metered API calls.
