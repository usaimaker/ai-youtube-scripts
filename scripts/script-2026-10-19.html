Why this matters

Most "AI agent" tutorials either drown you in Python or sell you a $500 course. n8n is open-source, drag-and-drop, and runs the same agent pattern the paid tools use: a model, memory, and tools. Once you see the skeleton, you can automate research, content, and outreach without writing code.

1. Start from the AI Agent node

Drop the "AI Agent" node onto the canvas and connect a Chat Trigger so you can talk to it from a simple web chat. This node is the brain — everything else just feeds it.

2. Give it a model (free tier works)

Attach an OpenAI or Ollama chat model as the agent's language model. Ollama runs locally and costs $0. Connect it to the agent's dedicated "chat model" slot, not the main flow.

3. Add memory so it remembers

Attach a Simple Memory or Window Buffer Memory node. Without memory the agent forgets everything after one message. Five clicks, zero code.

4. Hand it tools

Connect an HTTP Request or a dedicated tool node (like a search or a Google Sheet). Tools are what turn a chatbot into an agent that actually does things.

Automation tip

Swap the chat trigger for n8n's cron trigger to run the agent on a schedule — every morning it reads your inbox, summarizes it, and drafts replies. That is a $0 virtual assistant.
