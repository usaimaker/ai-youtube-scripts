Why this matters

A chatbot answers questions. A browser agent actually opens tabs and acts.

In 2026 several of these agents became free, so the entry cost is zero.

That turns hours of copy-paste research and form filling into a supervised background task.

1. Perplexity Comet, the free agent

Perplexity dropped Comet's paywall on March 18, 2026. It is now free worldwide.

It runs on Windows, macOS, Android, and iOS, and agent mode is included.

Free users get agentic search, page summaries, Deep Research, and a shopping assistant.

Multi-step autonomous tasks are rate limited on free, which is fine for daily chores.

2. Browser Use and Skyvern, the open-source route

Both are open-source frameworks that drive a real browser from your own code.

Self-hosting costs nothing beyond your machine and whatever model you point them at.

Use them when you need the same task repeated hundreds of times, reliably.

The trade-off is honest: you own the hosting and you own the guardrails.

3. Brave Leo, the private free option

Leo needs no login and does not tie chats to your identity.

It also offers on-device model options, so prompts can stay on your machine.

It is an assistant, not a full agent, so it summarizes rather than acts.

For sensitive reading work, that limitation is a feature, not a flaw.

4. Know what is actually paid

Gemini Auto Browse launched in Chrome on January 28, 2026, for AI Pro and Ultra subscribers.

Pro is about twenty dollars monthly and caps agent tasks at twenty per day.

Claude in Chrome ships with paid Claude plans and requests fifteen-plus browser permissions.

Try the free options first. Only pay once one workflow clearly saves you time.

5. Atlas is going away, plan around it

OpenAI announced on July 9, 2026 that ChatGPT Atlas is being retired.

The browser is scheduled to stop working on August 9, 2026.

Agentic browsing moves into the ChatGPT desktop app and a Chrome extension instead.

If you built habits in Atlas, migrate them this week.

Automation tip

Run agents in a separate browser profile with only the sites they need.

Never leave banking, admin, or password manager tabs open in that profile.

Hidden text on a malicious page can hijack an agent through prompt injection.

Simple rule: let agents handle tasks where a mistake costs a minute, not money.
