Why this matters

Cursor, Copilot and Claude Code all want twenty dollars monthly. That adds up fast for solo builders. Meanwhile the fastest-growing coding agents are open source and terminal-native. You keep the power and skip the bill.

1. Antigravity CLI (formerly Gemini CLI)

Google rebranded Gemini CLI as Antigravity CLI on June 18, 2026. Install it with npm i -g @antigravity/cli. You get 1,000 free requests per day, 60 per minute. No credit card, no API key setup. The one million token context window swallows a whole codebase.

2. Aider

Aider is the git-native pair programmer, Apache 2.0 licensed. Every edit becomes its own commit with a clear message. If a change breaks things, git revert undoes it instantly. Install with pip install aider-chat, then point it at a free Gemini key. That combination costs nothing for personal projects.

3. OpenCode

OpenCode supports 75 plus model providers, so you are never locked in. It has real language-server integration, giving the model type information and diagnostics. Run it with a cheap provider, or with Ollama locally for zero cost. Install with curl -fsSL https://opencode.ai/install.sh | bash.

4. Codex CLI (free, for now)

OpenAI made Codex CLI free for ChatGPT Free and Go users in March 2026. It is Rust-based, fast, and runs your code in a cloud sandbox. But the announcement gave no end date for the promotion. Treat it as a bonus, not a foundation. Keep a backup tool installed.

5. Goose, with honest expectations

Goose comes from Block and now sits under the Linux Foundation. It connects to thousands of MCP servers: GitHub, Jira, Slack, databases. One third-party benchmark scored it only 5.2 percent on coding correctness. So use Goose for workflow orchestration, not for delicate code edits.

Automation tip

The tool is free. The model usually is not. Point Aider or OpenCode at the free Gemini tier for daily work. Then run Antigravity CLI inside a GitHub Action for automatic pull-request reviews. Your laptop stays idle while the cloud does the reading.
