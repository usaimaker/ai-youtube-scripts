# 3 Open-Source Agent Frameworks That Shipped This Week (And What They Replace)

Hook: Three free frameworks dropped in one week, and each one kills a paid tool you might be paying for right now.

## Why this matters
Most people think getting better at AI means paying for a better model. This week proved the opposite. Three open-source releases all attack the same problem from different angles: making the agent around the model smarter, not the model itself. And all three are free, Apache licensed, and run on hardware you already own.

## 1. Google Harness2 - tune the agent, keep the model
Google Research open-sourced Harness2 on October 9. Instead of retraining a model, it optimizes everything around it: the system prompt, guardrails, memory, tool guidance, subagents, skills, scripts and plugins. The method is called Propose-Probe-Compose. It generates candidate changes, runs your task with each variant, and composes the winner from the evidence. No correct answer needed up front. Google reports gains up to 11.8 points on a legal benchmark with model weights completely unchanged. The repo is google-research/harness2, Apache 2.0.

## 2. Sakana AI The Agentic Scientist - a research team in a Docker container
Released October 15, also Apache 2.0. It runs multiple coding agents in parallel to handle the whole research loop: generate a hypothesis, run experiments, analyze results, draft the paper. A meta-controller coordinates the agents and every stage gets checked against a rubric before the next one starts. It works with Claude, Codex and Gemini. A development version already co-authored a paper accepted as an oral presentation at ALIFE 2026. The catch: these agents execute arbitrary commands, so run it isolated, never on your main machine.

## 3. Builder.io Agent-Native - agents and apps share one brain
The beta launched October 14. It is a TypeScript framework where the agent and the user interface share the same actions, data and state. You define a capability once and it appears in six places: the UI, the agent, an HTTP API, a CLI, MCP and A2A. Bring your own API keys, or run a local model through Ollama. Deploy to Vercel, Netlify, Cloudflare or AWS. The real win: the agent stops being a chatbot bolted onto your app and becomes part of the same system your users click through.

## The pattern worth copying
All three releases point the same direction. The model is becoming a commodity you rent by the token. The value moves to the harness: what instructions, tools, memory and guardrails you wrap around it. That is the part you control, the part that is free, and the part that compounds. If you are still paying for a premium tier to fix problems that are actually harness problems, this week is your sign to audit your setup before your next renewal.

## Automation tip

Change exactly one, measure the result, keep it only if it wins. That loop, run weekly, is the whole method. It costs nothing and it beats every model upgrade you have bought this year.
